# Class 1 · Balbharati rehearsal (staff only)

## Open

With a valid school/teacher account and the backend running, visit
`/school/curriculum-studio/1/2` through `/school/curriculum-studio/1/10`.
These are unpublished lesson *design previews*, not student routes. The school
studio verifies the backend design manifest before loading the preview.

## Rehearsal

1. Choose a textbook chapter and see its original Talkora teaching prompt,
   English model phrase and observable evidence criterion.
2. Toggle English / Hindi / Marathi; English remains the target language.
3. Toggle Model / Needs help / Practise / Extend to preview Miss Julie's
   short scripted coaching. **No mic, speech service, Qwen or learner scoring.**
4. Review real images/choices for each activity. When the prompt refers to a
   picture, the preview intentionally flags the missing approved visual.
5. Add notes and export a draft review JSON. These choices are local to the
   browser session; no approval or database update occurs.

## Release gate

All 44 original exercises and sample responses must be checked by a qualified
educator against the cited English Balbharati Standard One chapters/pages,
including actual approved visuals, bilingual wording, accessibility, consent,
audio and child-friendly evidence rules. Then separately connect their approved
runtime activities to Node/Python and test with supervised, credit-capped
Sarvam STT / Azure TTS. **Never unlock students from a staff preview** or
equate STT transcripts with IQ or pronunciation scoring.
